# vtclassic-editor

A cross-platform rebuild of the VirindiTank Classic loot editor (uTank2 Settings Editor 1.0.1.6).

- Spec: `specs/vtclassic-editor.md`. Task list and work rules: `PLAN.md`. Facts: `docs/README.md`.
- `ref/` links to the legacy C# source and the shipped binaries. It is read-only.
- Commands: `npm test`, `npm run typecheck`, `npm run build`, `npm run dev`.
- Do one task from `PLAN.md` for each session. Follow "How to work" in `PLAN.md`.
